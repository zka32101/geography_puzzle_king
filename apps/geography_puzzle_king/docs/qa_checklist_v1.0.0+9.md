## バグ報告

```
【バグID】BUG_001 【重大度】低
【概要】図鑑「統計」タブの「クリア県数」が実際より多く表示される
【再現手順】1. 同じ県を2回以上クリアする 2. 図鑑 → 統計
  → 実際: 2 / 47（北海道を2回クリア）  ホーム・図鑑「クリア県」・地図は 1 / 47
【期待動作】クリア済みの県の数（重複しない）を表示する
【原因】PlayerStats.totalClearedPrefectures がクリアの度に +1 する累積カウンター（game_provider.dart:190）。
        ホーム等は県ごとの記録から数えている。
【環境】Android 実機(A401OP) v1.0.0+9
```

```
【バグID】BUG_002 【重大度】中 【状態】修正済み（PR#33）
【概要】ランキングにスコアが登録されない（グローバル・都道府県対抗とも常に空）
【再現手順】1. ゲームをクリアする 2. ランキングを開く → 「まだランキングデータがありません」
【期待動作】クリアしたスコアがランキングに載る
【原因】ログインが端末内の仮ユーザー（uid=local_…、Firebase Auth未使用）。firestore.rules は
        request.auth.uid == uid を要求するため書き込みが拒否され、ranking_service.dart が例外を握りつぶす。
【影響】ストアの説明・スクリーンショットで「ランキング」をうたうと、ユーザーには機能しない。
【対処案】(a) Firebase 匿名認証でサインインし uid を一致させる (b) ランキングを一旦非表示にして説明から外す
【対処】(a) を採用（PR#33）。あわせて、認証が通ったことで表に出た別の重大な不具合も修正:
        runTransaction がネイティブ側で「transaction object cannot be used after its update callback」の
        Assertion で勝利直後にアプリごと落ちていた（重大度 高）。get→set に変更。
【実機確認】北海道 Easy をクリア → クラッシュなし（FATAL 0）。グローバルランキングに 1550 pts で1位表示。
【環境】Android 実機(A401OP) v1.0.0+9
```

```
【バグID】BUG_003 【重大度】低
```
